# Indie Founder Free Stack Cheat Sheet

## Problem
Kai saves lots of 'free tools / free credits / plugins' reels. That knowledge is scattered and decays fast.

## Concept
Keep a living note of the free stack + credits Kai can use (Cloudflare Pages/R2, Convex, Better Auth, PostHog, startup credit programs, Claude Code plugins like Superpowers / Karpathy rules), and later turn it into a 1-page printable 'Indie Builder Stack 2026' poster/cheat sheet for the dev audience.

## How to build it for real
1. Make a note 'Stack & Credits' in OmniBrain; verify each claim against the official page (some reel claims, like 'approved in 2 minutes', are hype).
2. Apply for legit startup programs only with a real business email (designedbykai domain).
3. Install Superpowers / Karpathy-style CLAUDE.md rules in Kai's repos and record results.
4. Optional: design a poster/cheat sheet for Etsy (dev-desk decor) once the list is stable.

## Etsy fit
Low as a product; mainly internal leverage. Poster version could sit in a 'developer gifts' niche.
